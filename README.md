# רצה: מרחק הפייסר לפי גובה

שרטוט אינטראקטיבי לפרויקט הפייסר האוטונומי (סטודיו 3, עצמים אוטונומיים). הדף מחשב כמה רחוק לפני הרצה הפייסר צריך לנוע כדי לשבת על קו הראייה הטבעי שלה, 15 מעלות מתחת לאופק, לפי גובה הרצה וגובה הפייסר.

- גובה עיניים = 0.936 × גובה הגוף (נגזר מנתונים אנתרופומטריים של מבוגרים בריטים).
- מרחק = 3.73 × (גובה עיניים פחות גובה הפייסר).

הדף עצמו: `index.html`. קבצי המקור של השרטוט נמצאים בתיקייה `source/`. כדי לבנות מחדש מריצים `python3 source/build.py`.
